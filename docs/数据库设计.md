# 数据库设计

数据库名 `campus_card`，字符集 `utf8mb4`，存储引擎 `InnoDB`。
**金额一律使用 `DECIMAL(12,2)`，禁止使用浮点类型**，避免精度丢失（见 `src/main/resources/schema.sql`）。
建表语句为幂等（`IF NOT EXISTS`），演示数据见 `sql/init.sql`（`INSERT IGNORE`，可重复执行）。

## 表总览（8 张）

| 表名 | 说明 | 关键字段 |
| --- | --- | --- |
| `card` | 校园卡 | card_no（唯一）、card_type、status、pin、version（乐观锁） |
| `account` | 一卡通账户 | card_id、balance、points、frozen_amount、version |
| `terminal` | 消费终端 | terminal_no（唯一）、terminal_type、secret、status |
| `transaction` | 交易主表 | tx_no（唯一）、idempotency_key（唯一）、amount、discount_amount、actual_amount、strategy_type、status |
| `transaction_item` | 交易明细 | tx_no、item_name、quantity、unit_price、amount |
| `reconcile_record` | 终端对账记录 | terminal_id、settle_date、tx_count、total_amount、status |
| `notify_log` | 通知 / 审计日志 | tx_no、channel（PUSH/AUDIT）、content |
| `points_log` | 积分流水 | card_id、tx_no、points_change、balance_after |

## 字段约定与约束

- **状态枚举**
  - `card.status`：`NORMAL` / `LOST` / `FROZEN` / `CANCELLED`
  - `card.card_type`：`STUDENT` / `TEACHER`
  - `terminal.terminal_type`：`POS` / `SUPERMARKET` / `ACCESS` / `WATER`
  - `terminal.status`：`ENABLED` / `DISABLED`
  - `transaction.tx_type`：`RECHARGE` / `CONSUME` / `REFUND`
  - `transaction.status`：`SUCCESS` / `FAILED` / `REVERSED`
  - `reconcile_record.status`：`PENDING` / `BALANCED` / `DIFF`

- **乐观锁**：`card` 与 `account` 均带 `version` 字段，扣款使用
  `UPDATE ... SET balance = balance - ? , version = version + 1 WHERE id = ? AND version = ?`
  实现并发安全（见 `AccountDao.atomicDeduct`）。

- **幂等**：`transaction.idempotency_key` 唯一，配合责任链 `IdempotencyHandler` 防重复消费。

- **外键**：`account.card_id → card.id`、`transaction.card_id → card.id`、
  `transaction.terminal_id → terminal.id`、`transaction_item.tx_id → transaction.id`、
  `reconcile_record.terminal_id → terminal.id`。

## 核心索引

- `uk_card_no`、`uk_terminal_no`、`uk_tx_no`、`uk_idempotency_key` 保证业务唯一性；
- `idx_tx_card_time(card_id, created_at)`、`idx_tx_terminal_time(terminal_id, created_at)`、
  `idx_tx_type_status(tx_type, status)` 支撑按卡 / 终端 / 类型的高频查询与统计。
