# 本地部署指南

## 一、环境要求

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 8 | 后端编译与运行 |
| Maven | 3.6+ | 构建后端（也可用 `mvnw`） |
| MySQL | 8.0 | 数据库（5.5 需按第四节处理） |
| Node.js | 18+ | 含 npm，运行前端 |

## 二、初始化数据库

```bash
# Windows 必须带 --default-character-set=utf8mb4，否则中文姓名会乱码
mysql -uroot -p --default-character-set=utf8mb4 < sql/init.sql
```

脚本会创建 `campus_card` 库、8 张表，并写入演示数据（卡、终端、历史交易、对账记录等）。
演示账号见项目 README「演示数据」一节。

## 三、启动后端

修改 `src/main/resources/application.yml` 中的数据库连接（默认 `root/123456`）。

```bash
# 方式一：直接运行（端口 8080）
mvn spring-boot:run

# 方式二：打包后运行
mvn clean package -DskipTests
java -jar target/campus-card-1.0.0.jar
```

后端启动后，所有接口位于 `http://localhost:8080/api/...`。

## 四、启动前端

```bash
cd frontend
npm install
npm run dev      # Vite 开发服务器，端口 5173，已配置 /api 代理到 8080
```

浏览器打开 `http://localhost:5173` 即可使用管理端。
若不方便安装 Node，可直接双击根目录 `界面预览.html` 查看界面布局与交互演示（Vue 3 CDN，需联网）。

## 五、在 IDE 中运行

- **IntelliJ IDEA**：导入 Maven 工程，运行 `CampusCardApplication`；前端用 VS Code 打开 `frontend` 执行 `npm run dev`。
- **端口冲突**：若 8080 被占用，修改 `application.yml` 的 `server.port` 与 `frontend/vite.config.js` 中 proxy 的目标端口保持一致。
- **MySQL 5.5 用户**：本工程 SQL 按 MySQL 8.0 编写（如 `utf8mb4_0900_ai_ci` 排序规则、部分语法）。
  在 5.5 上需手动把建表语句的字符集/排序规则改为 `utf8` / `utf8_general_ci`，并核对函数兼容性。

## 六、停止

- 后端：在启动终端 `Ctrl + C`；后台进程可按端口查杀（如 `netstat -ano | findstr :8080` 后 `taskkill /PID <pid> /F`）。
- 前端：`Ctrl + C` 关闭 Vite。
